my-ai — goose via the my-ai-api OpenRouter router + Headroom compression proxy
(universal: KDE / TTY / Termux)

USAGE
  my-ai [--agent goose|claude-cli|claude-cli-ghost|hermes] [remote|local|goose]
        [headroom on|off] [rtk on|off] [caveman on|off]
        [fresh|sync|restore …|restore-hours …|list …|list-hours …] [agent args…]

my-ai wraps one of three agents (selectable via --agent or the dashboard AGENT
section): goose (Block, default), claude-cli (Anthropic Claude Code), or hermes
(Nous Research — a goose shim pinned to a Hermes model on OpenRouter). my-ai-api
(sibling of claude-superset-api on oci-apps) routes OpenRouter — NOT Claude —
and adds a vendored Headroom (Apache-2.0) compression hop in front of every call.
goose/hermes point at my-ai-api as a custom OpenAI provider (OPENAI_BASE_URL);
claude-cli points at my-ai-api's anthropic shim (ANTHROPIC_BASE_URL, itself a
shape-translation onto OpenRouter — NOT real Claude). The container injects the
real OPENROUTER_API_KEY, so the client needs no upstream key of its own.

AGENT (--agent, default: goose / MY_AI_AGENT env)
  goose                Block's goose CLI → my-ai-api (OpenRouter, OpenAI shape).
  claude-cli           Anthropic Claude Code CLI → my-ai-api (anthropic shim).
  claude-cli-ghost     Claude Code CLI in a throwaway HOME ($HOME/.claude-ghost),
                       wiped to login-only on every launch — a real ghost: HOME is
                       relocated so ALL home layers reset (~/.claude, ~/.claude.json,
                       ~/CLAUDE.md), not just CLAUDE_CONFIG_DIR. Fresh anonymous
                       Claude (no history/projects/memory/settings); nothing real is
                       touched, so a crash can't strand your config. MCP comes ONLY
                       from ~/.config/my-ai/mcp-ghost.json (--strict-mcp-config) —
                       your user MCP and the project ./.mcp.json are ignored. Edit
                       that file to give the ghost its own curated servers.
  hermes               Nous Research Hermes → goose shim pinned to a Hermes model
                       (nousresearch/hermes-3-llama-3.1-405b) on OpenRouter via
                       my-ai-api. No standalone hermes CLI exists.

FACE (default: remote)
  remote                Route goose through the my-ai-api router on oci-apps over
                        WireGuard (goose uses OPENAI_BASE_URL=http://10.0.0.6:3217/v1).
  local                 Run the same my-ai-api container on THIS host (docker
                        compose, 127.0.0.1 only). `local down` tears it down.
                        (Desktop only — no docker in Termux/TTY.)
  goose                 Bypass everything — plain goose with its native provider
                        (no my-ai-api hop, no compression plugins).

MODE (comes first; default: --auto)
  --auto                Auto-approve: passed through to goose as needed.
  --plan                Plan-first mode: recorded for display.
  --interactive         Explicit interactive mode.
  --model <id>          Override the model (sets GOOSE_MODEL; any OpenRouter slug
                        or a short alias from build.json runtime.model_aliases).
  --effort <lvl>        Effort tier (informational; sets MY_AI_EFFORT).

  Mode + model flags must appear before all other arguments.

PLUGIN TOGGLES (any order, before the action)
  headroom on|off       on = compress via the my-ai-api Headroom sidecar (sets
                        OPENAI_BASE_URL so goose's traffic is routed + compressed).
                        off = plain goose with its native provider (no compression).
  rtk on|off            RTK (Rust Token Killer): strip CLI/test noise BEFORE
                        Headroom compresses. (RTK_ENABLED)
  caveman on|off        Caveman: linguistic/conversational compression.
                        (CAVEMAN_ENABLED)

  (ponytail is a Claude-Code-specific hook system; it has no goose equivalent and
  is accepted but ignored by my-ai.)

SESSION ACTION (default: fresh)
  fresh                 Normal fresh goose session (execs `goose session`).
  sync                  Push the last N local sessions to the hub (also runs
                        automatically in the background on every fresh launch).
                        NOTE: goose stores sessions in SQLite; .jsonl sync/restore
                        is being migrated to `goose session export/import` — until
                        then sync/restore are best-effort and may find no sessions.
  restore <X>           Reopen this device's last X sessions, one per tab/window.
  restore-hours <Y>     Reopen this device's sessions from the last Y hours.
  restore <device> <X>  Reopen the last X sessions from another device.
  restore all <X>       Reopen the last X sessions across ALL devices.
  list <X>              Print this device's last X sessions (id + title); no launch.
  list-hours <Y>        Print this device's sessions from the last Y hours; no launch.

USAGE / TOKEN TRACKING
  usage                  Native ccusage-equivalent token-usage report. Scans
                        every ~/.claude/projects/**/*.jsonl transcript, dedups
                        by message.id+requestId, buckets into ccusage-style
                        5-hour billing blocks, and prices them (longest-prefix
                        match against ~/.claude/claude-pricing.json, else a
                        bundled default table). Prints the last ~5 blocks,
                        highlighting the ACTIVE one with burn rate + reset ETA.
  usage --json           Machine-readable JSON: {active_block, blocks:[...]}.
  usage --statusline     Single-line, ANSI-colored summary for a statusline
                        host (printed via printf %b) — prints NOTHING and
                        exits 0 if idle (no active block). Cached for 30s
                        ($STORE/usage-statusline.cache) so it's cheap to call
                        on every render.
  usage --since <hours>  Restrict the report to usage from the last N hours.

SETUP (installer / deps-solver)
  setup                 Ensure `goose` is installed. Platform-aware:
                        nix/termux = flake-managed (declarative); other = goose
                        releases (github.com/block/goose).
  setup --shell         Ephemeral goose via nix-shell (temporary use).
  setup rescue [args]   Fallback chain: podman -> npx -> nix -> cargo.

OTHER
  (no args) / -h / --help / dash   Live status dashboard (my-ai-dash).
  help                             This message.
  --version                        Print version.

EXAMPLES
  my-ai                                # dashboard
  my-ai remote                         # remote, fresh, headroom on (default)
  my-ai local                          # local face, fresh
  my-ai headroom off                   # plain goose, no compression
  my-ai --model openai/gpt-4o          # override model (OpenRouter slug)
  my-ai goose                          # bypass — plain goose
  my-ai sync                           # push local sessions to the hub now
