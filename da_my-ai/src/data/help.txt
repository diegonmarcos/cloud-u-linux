my-ai — Claude Code (or goose/hermes) via the my-ai-api OpenRouter router +
Headroom compression proxy (universal: KDE / TTY / Termux).

USAGE
  my-ai [--agent claude-superset|goose|claude-cli|claude-cli-ghost|hermes]
        [remote|remote-tmux_<vm>|local|goose] [headroom on|off] [rtk on|off] [caveman on|off]
        [claude <profile>] [ponytail on|off|lite|full|ultra]
        [fresh|sync|restore …|restore-hours …|list …|list-hours …] [agent args…]

my-ai wraps one of five agents (selectable via --agent or MY_AI_AGENT).
claude-superset (the default) is a self-contained wrapper that does its own
face/headroom/plugin wiring — the other four agents are wired directly to
my-ai-api (sibling of claude-superset-api on oci-apps), which routes
OpenRouter — NOT Claude — and adds a vendored Headroom (Apache-2.0) compression
hop in front of every call. goose/hermes point at my-ai-api as a custom OpenAI
provider (OPENAI_BASE_URL); claude-cli points at my-ai-api's anthropic shim
(ANTHROPIC_BASE_URL, itself a shape-translation onto OpenRouter — NOT real
Claude). The container injects the real OPENROUTER_API_KEY, so the client
needs no upstream key of its own.

my-ai-dash (the ratatui TTY dashboard) has been discontinued. This --help text
is now the only helper surface; `dash` as an argument prints a discontinued
notice and this same text.

AGENTS (--agent, default: claude-superset / MY_AI_AGENT env)
  claude-superset      DEFAULT. Anthropic Claude Code, run through the
                       claude-superset wrapper (claude-superset.nix) — the
                       same wrapper my-ai itself was forked from. It is
                       self-contained: it does its own remote/local face
                       detection, headroom/rtk/caveman/ponytail plugin wiring,
                       and session restore, once exec'd. my-ai sets NO
                       ANTHROPIC_*/OPENAI_*/GOOSE_* env for it — doing so would
                       be ignored noise at best — and forwards the passthrough
                       args verbatim, since claude-superset's own CLI shape
                       ([local|remote|claude] [headroom on|off] [ponytail
                       on|off|lite|full|ultra] [rtk on|off] [caveman on|off]
                       [restore N | restore-hours N | sync | fresh
                       [claude-args…]]) is what route() below already mirrors.
  goose                Block's goose CLI → my-ai-api (OpenRouter, OpenAI
                       shape). Remote face runs the agent loop server-side
                       (goosed on oci-apps, HTTP/SSE); local face execs `goose
                       session` locally against the my-ai-api router.
  claude-cli           Anthropic Claude Code CLI → my-ai-api's anthropic shim
                       (ANTHROPIC_BASE_URL).
  claude-cli-ghost     Claude Code CLI in a throwaway HOME ($HOME/.claude-ghost),
                       wiped to login-only on every launch — a real ghost: HOME is
                       relocated so ALL home layers reset (~/.claude, ~/.claude.json,
                       ~/CLAUDE.md), not just CLAUDE_CONFIG_DIR. Fresh anonymous
                       Claude (no history/projects/memory/settings); nothing real is
                       touched, so a crash can't strand your config. MCP comes ONLY
                       from ~/.config/my-ai/mcp-ghost.json (--strict-mcp-config) —
                       your user MCP and the project ./.mcp.json are ignored. Edit
                       that file to give the ghost its own curated servers.
  hermes               Nous Research Hermes → goose shim pinned to a Hermes model
                       (nousresearch/hermes-3-llama-3.1-405b) on OpenRouter via
                       my-ai-api. No standalone hermes CLI exists.

FACES (default: remote)
  remote                Route the agent through the my-ai-api router on
                        oci-apps over WireGuard.
  remote-tmux_<vm>      SSH to <vm> once (e.g. remote-tmux_oci-apps) and run
                        the agent inside a tmux session there. Phone RAM: ~5-15MB
                        vs ~50-75MB for 5 raw SSH tabs. Network drops don't kill
                        your sessions — tmux keeps them alive on the server.
                        Default: attach to existing "my-ai" session (reconnect),
                        or create it with the agent in window 0 if new.
                        fresh: always open a new agent window in the session.
  local                 Run the same my-ai-api container on THIS host (docker
                        compose, 127.0.0.1 only). `local down`/`local stop`
                        tears it down. (Desktop only — no docker in Termux/TTY.)
  goose                 Bypass everything — plain exec of the chosen agent
                        with its native provider (no my-ai-api hop, no
                        compression plugins, no auto-sync). Despite the name,
                        this bypass face works for any --agent, not just goose.

MODE FLAGS (must come before the session action)
  --agent <id>          claude-superset | goose | claude-cli |
                        claude-cli-ghost | hermes. See AGENTS above.
  --model <id>          Override the model (sets GOOSE_MODEL + ANTHROPIC_MODEL;
                        any OpenRouter slug or a short alias from
                        build.json runtime.model_aliases).
  --effort <lvl>        Effort tier (informational; sets MY_AI_EFFORT).
  --auto                Auto-approve: recorded for display.
  --plan                Plan-first mode: recorded for display.
  --interactive          Explicit interactive mode.

PLUGIN TOGGLES (any order, before the session action)
  headroom on|off       on = compress via the my-ai-api Headroom sidecar
                        (routes the agent's traffic through the compression
                        hop). off = plain agent, native provider, no
                        compression.
  rtk on|off            RTK (Rust Token Killer): strip CLI/test noise BEFORE
                        Headroom compresses. (RTK_ENABLED)
  caveman on|off        Caveman: linguistic/conversational compression.
                        (CAVEMAN_ENABLED)
  ponytail on|off|lite|full|ultra
                        Claude-Code-specific hook system (PONYTAIL_DEFAULT_MODE).
                        Only meaningful for the claude-superset/claude-cli*
                        agents; accepted but has no effect on goose/hermes.
  claude <profile>      Claude Code context profile (only affects --agent
                        claude-cli / claude-cli-ghost). Sets env flags from
                        the matching profile in endpoints.json; shown in the
                        startup banner. Tool schemas are built once at
                        startup, so pick the profile at launch — switching
                        mid-session does not reload them.

SESSIONS (default: fresh)
  fresh                 Normal fresh agent session (default action).
  sync                  Push the last N local sessions to the hub (also runs
                        automatically in the background on every fresh launch).
  restore <X>           Reopen this device's last X sessions, one per tab/window.
  restore-hours <Y>     Reopen this device's sessions from the last Y hours.
  restore <device> <X>  Reopen the last X sessions from another device.
  restore all <X>       Reopen the last X sessions across ALL devices.
  list <X>              Print this device's last X sessions (id + title); no launch.
  list-hours <Y>        Print this device's sessions from the last Y hours; no launch.

USAGE / TOKEN TRACKING
  usage                  Native ccusage-equivalent token-usage report. Scans
                        every ~/.claude/projects/**/*.jsonl transcript, dedups
                        by message.id+requestId, buckets into ccusage-style
                        5-hour billing blocks, and prices them (longest-prefix
                        match against ~/.claude/claude-pricing.json, else a
                        bundled default table). Prints the last ~5 blocks,
                        highlighting the ACTIVE one with burn rate + reset ETA.
  usage --json           Machine-readable JSON: {active_block, blocks:[...]}.
  usage --statusline     Single-line, ANSI-colored summary for a statusline
                        host (printed via printf %b) — prints NOTHING and
                        exits 0 if idle (no active block). Cached for 30s
                        ($STORE/usage-statusline.cache) so it's cheap to call
                        on every render.
  usage --since <hours>  Restrict the report to usage from the last N hours.

SETUP (installer / deps-solver, for the goose agent)
  setup                 Ensure `goose` is installed. Platform-aware:
                        nix/termux = flake-managed (declarative); other = goose
                        releases (github.com/block/goose).
  setup --shell         Ephemeral goose via nix-shell (temporary use).
  setup rescue [args]   Fallback chain: nix -> podman -> cargo.

OTHER
  (no args) / -h / --help / dash   Print this help text. (my-ai-dash, the
                                   former live TTY dashboard, is discontinued.)
  help                             Same as --help.
  --version                        Print version.
  ant [args…]                     Thin passthrough — exec the `ant` CLI
                                   (Anthropic Developer Platform) verbatim.
  gemini [args…]                  Thin passthrough — exec the `gemini` CLI.
  antigravity [args…]             Thin passthrough — exec Google Antigravity.

EXAMPLES
  my-ai                                 # help text
  my-ai remote                          # claude-superset, remote, fresh (default)
  my-ai local                           # local face, fresh
  my-ai headroom off                    # native provider, no compression
  my-ai --agent goose remote            # goose agent instead of claude-superset
  my-ai --model openai/gpt-4o           # override model (OpenRouter slug)
  my-ai goose                           # bypass face — plain exec, no my-ai-api hop
  my-ai sync                            # push local sessions to the hub now
  my-ai remote-tmux_oci-apps           # SSH once to oci-apps, attach/create tmux session
  my-ai remote-tmux_oci-apps fresh     # + open a new claude window in that session
