claude-superset — Claude Code via the Headroom compression proxy (universal: KDE / TTY / Termux)

USAGE
  claude-superset [remote|local] [headroom on|off] [ponytail on|off|<level>]
                  [fresh|sync|restore …|restore-hours …|list …|list-hours …] [claude args…]

FACE (default: remote)
  remote                Route through the oci-apps proxy over WireGuard
                        (direct-Anthropic fallback if unreachable).
  local                 Run the same container on THIS host (docker compose,
                        127.0.0.1 only). `local down` tears it down.
                        (Desktop only — no docker in Termux/TTY.)
  claude                Bypass everything — plain claude, no proxy/engine/plugins.

MODE (comes first; default: --auto)
  --auto                Auto-approve: passes --dangerously-skip-permissions to
                        Claude. Claude acts without per-tool permission prompts.
                        This is the DEFAULT — no flag needed.
  --plan                Plan-first mode: record intent for display. Future CLI
                        flag when Claude Code adds native plan mode support.
  --interactive         Explicit standard interactive mode. Claude asks before
                        each action (override if auto was set elsewhere).

  --model <id>          Override the model (sets ANTHROPIC_MODEL env var).
                        IDs: claude-sonnet-4-6 · claude-opus-4-8 · claude-haiku-4-5
  --effort <lvl>        Effort tier (sets CLAUDE_EFFORT env): high|medium|low.
                        Default: model decides.

  Mode + model flags must appear before all other arguments.

PLUGIN TOGGLES (any order, before the action)
  headroom on|off       on  = compress via the proxy (sets ANTHROPIC_BASE_URL).
                        off = direct to Anthropic, no compression.
  ponytail on|off|LVL   Set ponytail mode. LVL = lite|full|ultra.
                        on = full, off = disabled.
  rtk on|off            RTK (Rust Token Killer): strip CLI/test noise BEFORE
                        Headroom compresses. Default on. (RTK_ENABLED)
  caveman on|off        Caveman: linguistic/conversational compression.
                        Default on. (CAVEMAN_ENABLED)

SESSION ACTION (default: fresh)
  fresh                 Normal fresh session (passes remaining args to claude).
  sync                  Push the last N local sessions to the hub (also runs
                        automatically in the background on every fresh launch).
  restore <X>           Reopen this device's last X sessions, one per tab/window.
  restore-hours <Y>     Reopen this device's sessions from the last Y hours.
  restore <device> <X>  Reopen the last X sessions from another device.
  restore all <X>       Reopen the last X sessions across ALL devices.
  list <X>              Print this device's last X sessions (id + title); no launch.
  list-hours <Y>        Print this device's sessions from the last Y hours; no launch.
                        (Remote sessions are re-homed under $HOME so they resume
                        on this device.)

  Tabs use the best terminal available: konsole (KDE) → tmux (TTY/Termux).

SETUP (installer / deps-solver — NO npm, native binaries)
  setup                 Ensure `claude` is installed. Platform-aware:
                        nix/termux = flake-managed (declarative, guides you);
                        deb/linux/macos = Anthropic native installer
                        (downloads.claude.ai) + installs curl if missing.
  setup --shell         Ephemeral claude via nix-shell (temporary use,
                        no permanent install).
  setup rescue [args]   Run claude via a fallback chain when it's not installed:
                        podman -> npx -> nix -> node (reuses tools/claude-rescue
                        when present). Last-resort, ephemeral.

OTHER
  --help, -h, h         Interactive status dashboard (faces, MCPs, plugins).
  help                  This text + live status: agents, plugin status line,
                        and recent sessions (last 48h + last 5 by time).

my-ai                   Alias for claude-superset (future replacement). Same
                        script, same flags, same behaviour.

EXAMPLES
  claude-superset                              # auto mode, remote, fresh, headroom on
  my-ai                                        # same (alias)
  claude-superset --auto                       # explicit auto mode (same as default)
  claude-superset --plan                       # plan-first mode
  claude-superset --interactive                # interactive mode (ask per action)
  claude-superset --model claude-opus-4-8      # override model
  claude-superset --effort high                # override effort tier
  claude-superset local ponytail ultra         # local face, ponytail ultra
  claude-superset headroom off                 # direct, no compression
  claude-superset restore 5                    # reopen last 5 local sessions
  claude-superset restore-hours 8              # reopen local sessions from last 8h
  claude-superset restore android-termux 3     # reopen 3 sessions from the phone
  claude-superset restore all 10               # reopen last 10 across all devices
  claude-superset sync                         # push local sessions to the hub now
  claude-superset help                         # this text + live status + sessions
